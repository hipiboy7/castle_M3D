## ⏱ 2분 확인 경로 (v0.7.0-rc.22 — 원작 웹툰 2D 포트레이트/전 챕터 대사창 · 대형 컷인 타이포 · 3단계 만화 3D 파일럿 9종)

1. **처음 화면(타이틀 4버튼 메뉴 & 데모 복귀)**:
   - 앱 실행 후 6초 이상 가만히 두어 데모가 시작되면 화면을 눌러 **다시 타이틀 4버튼(`이어서 하기`/`스테이지 선택`/`처음부터`/`끝내기`) + 좌상단 `난이도` 표시 상태**로 돌아오는지 확인
2. **프롤로그(0장) — 주점(`vlad_bar`) 카메라 · 리빌 · 원작 대사창**:
   - 시작 직후 카메라가 문으로 걸어 들어오는 **의뢰인 여성**을 따라가고, 왼쪽 구석 안락의자의 **김신은 보이지 않는지(어둠 속에 숨김)** 확인
   - 대화가 기존 말풍선 대신 **원작 정연 웹툰 2D 스탠딩 + 이름표 리본 + 하단 대사창**으로 선명하게 출력되는지 확인
   - 리사의 `"아무르 티그로의 은퇴식에 어울릴 만한."` 대사 직후 **스탠딩이 정리되며 구석 김신에게 스포트라이트 점등 + `아무르 티그로 / 김신 · 마지막 의뢰` 대형 사선 컷인**이 터지고 김신이 일어서서 걸어 나가는지 확인
3. **`스테이지 선택` → 6장 인천항 부두(`ch6`) — 대형 컷인 · 쳐내기 중복 제거 · 만화 3D**:
   - 입장 시 **원작 백도찬(파이톤 + 안경) 사선 컷인**이 더 오래(`1.55s`) 유지되고, **대형 글자(`68pt`)**가 한눈에 읽히는지 확인
   - **실제 3D 전투 캐릭터(김신 · 백도찬)**가 원작 얼굴 투영 + 조각 3D 헤어 + 백도찬 흰 셔츠/가죽 X홀스터/안경 + 만화 셀/외곽선으로 원작 컷인과 더 닮아졌는지 확인
   - **기술 / 카운터 / 2차 페이즈** 컷인의 대형 글자 가독성 확인
   - **쳐내기(패리)** 첫 성공 시에만 사선 컷인이 발동하고, 2회차 이후 성공부터는 컷인 도배 없이 월드 텍스트(`쳐내기!`)만 깔끔하게 뜨는지 확인
4. **`스테이지 선택` → 1장 1번 방(`site_alley`) / 2장 8번 방(`haseong_ceo`) / 5·7·9장 대화 방**:
   - **전 챕터 대화**(0~13장 컷신·원작 대사·대화 방·전투 중 대사)가 스쳐 지나가는 말풍선 대신 **2D 원작 웹툰 스탠딩/초상화 + 이름표 리본 + 대사창**으로 통일되었는지 확인
   - **서진태(분홍 점퍼·금발 투블럭·노란 선글라스) · 오지인(올림머리·와인 스커트·일본도) · 리사(모피 코트·금발 웨이브) · 의뢰인 여성**의 3단계 만화 3D 모델 외형 확인
