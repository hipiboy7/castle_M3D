## 📱 설치

1. 휴대폰 **GitHub 앱** → 아래 **Repositories** → `castle_M3D` → **Releases** → 맨 위(**Latest**) 릴리스
2. 아래 **Assets** 에서 `castle_m3d-<버전>.apk` 를 눌러 받고 → 열어서 **설치**(처음이면 '출처를 알 수 없는 앱' 허용)
3. 전에 깐 캐슬 M 3D 위에 그대로 덮어 설치된다(같은 서명 키)

## ⏱ 1분 플레이 경로 (v0.7.0-rc.8 — 장별 대결 구도 · 기술 이름별 동작)

처음 화면 → **13장** 카드(또는 이어하기). 첫 방에서 김신 옆에 도학수 · 어광득이 아군(초록 고리)으로 서고, 계단 · 주먹 승부에서 피우진이 적으로 나오는지 본다.

## ✅ 이번에 볼 것 (v0.7.0-rc.8)

- [ ] **장별 편 · 방 차례**(castle_common 원작 싸움 기록대로 0 ~ 13장 다시 맞춤):
  - 13장: 김신(백의) + 도학수 · 어광득 대 미술관 경비 · 경호대 → 주먹 승부 피우진(적). 사인진 방은 없앴다(맺음 대사로)
  - 1장 거리 방은 서진태 조작(원작에서 서진태가 DS 를 뚫는다) · 3장 감방은 이슬 대 구일화 일대일, 부산 거리에서 샤이어 · 서진태가 아군 · 4장 장호는 적이 아니라 포로(폐공장 적은 바리스타 무리), 구스타프는 물러남
  - 6장 앞 · 9장: 이스크라(메드베디 · 라텔)가 적이 아니라 아군 · 9장 사무실은 똘배 조작 · 김신은 보스실 대화
  - 10장 한태철 아군 · 링링 방 새로 · 11장 하야부사 방 없앰(원작에서 김신과 안 싸움) · 12장 방 차례 · 최혁진 아군 · 하역장 방 새로
- [ ] **기술 이름별 동작**(157개를 원작 묘사대로 — 자세 35가지 새로): 기술 버튼으로 하나씩 써 본다.
  - 김신 '숙여 흘리고 카운터 주먹' = 숙여 기다리다 맞으면 흘리고 턱 올려치기 · 구일화 '들이받기' = 박치기 · 이슬 메다꽂기 = 붙잡아 메치기 · 신겐 날아차기 = 떠서 차기
  - 적이 머리 위에 기술 이름을 띄울 때 그 이름대로 움직이는지(같은 사람이 모든 기술을 같은 주먹으로 치지 않는지)
  - 맨손 방(0 · 1장 · 13장 주먹 승부 등)에서는 칼 · 총 기술이 목록에서 빠진다
- [ ] **어려운 방**: 10장 리천 · 11장 신겐 · 12장 마학영 · 13장 주먹 승부를 다시 맞췄다(봇 8판 5 ~ 6판 이김) — 보통 난이도에서 이길 만한지
- [ ] **화면 껐다 켜기**: 다시 검은 화면이 나오면 장 · 화면 상황을 알려 주면 된다
