## 📱 설치

1. 휴대폰 **GitHub 앱** → 아래 **Repositories** → `castle_M3D` → **Releases** → 맨 위(**Latest**) 릴리스
2. 아래 **Assets** 에서 `castle_m3d-<버전>.apk` 를 눌러 받고 → 열어서 **설치**(처음이면 '출처를 알 수 없는 앱' 허용)
3. 전에 깐 캐슬 M 3D 위에 그대로 덮어 설치된다(같은 서명 키)

처음 화면 '그림' 버튼으로 **A** → **2장** 카드 → 대표실 앞 복도(메뉴 → 스테이지)에서 **오지인** 얼굴 · 몸을 본다 → '그림'을 B · 인형으로 바꿔 한 번씩.

### 묶음 B — 기술 · 밸런스 (새로)
- [ ] **대시 버튼**: 누르면 짧게 빠르게 내달리고, 대시 중(또는 직후) **베기 = 대시기**(김신 칼: 아무르 티그로 대시 — 낮게 찌르기)
- [ ] **원콤**: 김신(내성 중위)은 **준10강 이하 무리**를 보통 공격 한 대에(서진태 외성 하위는 네임드 이하). 방의 보스 · 조작 인물은 빼고 — '팍팍 쓸어버리는 느낌'인지
- [ ] **김신 기술**(기술 바꾸기 버튼으로 고름): 각법 · **좌우로 사라지는 스텝**(무적 · 좌우 · 두 번 찌르기, 내성 중위 이하 못 막음) · **아무르 티그로 3연타**(쾅! 쾅! 쾅! · 0.5초 기절) · **아무르 티그로 위빙**(2칸 — 무적 세 대, 외성 이하 무리 한 방). 리천식 삼연타는 없다(리천전 뒤에 얻음)
- [ ] **서진태 기술**(2장): **근거리 급소 베기**(1칸 — 붙어서 빠르게) · **서진태 난무**(3칸 — 둘레 전부). **서진태 오리지널**은 공통 진행대로 6장 코모도전 뒤에 얻는다(2장엔 없음)
- [ ] **피우진(11장)**: **미친 코어 카운터** — 누르고 몸을 낮춘 사이 공격이 오면 '카운터!' 맞받아 1초 기절
- [ ] 보스(신태진 · 황보민철 · 오지인 · 남궁혁)는 원콤이 안 된다 — 새 기술로 너무 쉬워졌는지 · 어려운지
