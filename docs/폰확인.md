## 📱 설치

1. 휴대폰 **GitHub 앱** → 아래 **Repositories** → `castle_M3D` → **Releases** → 맨 위(**Latest**) 릴리스
2. 아래 **Assets** 에서 `castle_m3d-<버전>.apk` 를 눌러 받고 → 열어서 **설치**(처음이면 '출처를 알 수 없는 앱' 허용)
3. 전에 깐 캐슬 M 3D 위에 그대로 덮어 설치된다(같은 서명 키)

## ⏱ 1분 플레이 경로 (v0.7.0-rc.6 — 김신 새 모델 · 인물 기술 · 장 넘어가기)

처음 화면 → **이어하기**(또는 열린 장 카드). 그림은 처음 화면 '그림' 버튼이 **A** 일 때 새 김신 모델이 보인다 — 6장 결투 · 11장 호텔이 보기 좋다.

## ✅ 이번에 볼 것 (v0.7.0-rc.6)

- [ ] **김신 새 모델(시범 — 김신만)**: 그림 A 에서 김신이 매끈한 정장 인물(얼굴 · 머리카락 · 옷깃 · 주먹)로 바뀌었는지, 싸움 동작(베기 · 찌르기 · 차기 · 구르기 · 쓰러짐)이 어색하지 않은지. 다른 인물은 아직 예전 모습이라 김신만 날씬해 보인다 — **이 방향으로 전원을 바꿀지** 알려 주면 된다. 그림 B(도트) 김신은 아직 예전 모습
- [ ] **인물 기술**(등급 수만큼 — 재앙 전부 · 톱 7 · 내성 5 · 외성 4 · 그 아래 3): 기술 바꾸기 버튼으로 조작 인물의 기술 목록이 늘었는지(12장부터 김신은 재앙이라 아주 많다). 이름 있는 적이 가끔 머리 위에 원작 기술 이름을 띄우며 치는지(경호원 같은 무리는 안 띄운다)
- [ ] **장 넘어가기 · 잠김**: 5 · 6장이 열렸는지(뒤 장을 깬 기록이 있으면 그 앞 장은 모두 열린다). 4장 · 12장을 한 번 더 깨면 5장 · 13장으로 넘어가는지(싸움 중 메뉴로 스테이지를 골라 시작하거나 난이도를 바꿔 다시 한 판도 깨면 기록된다)
- [ ] **어려웠던 방**: 3장 청주 감방(구일화) · 4장 폐저수지 · 12장 녹색 사무실(구스타프)이 보통 난이도에서 이길 만한지(기술이 들어가며 다시 맞췄다)
- [ ] **화면 껐다 켜기**: 다시 검은 화면이 나오면 ① 소리 ② 누름 · 뒤로 버튼 ③ 홈 → 다시 열기 ④ 접힘 여부를 알려 주면 된다

결과는 Claude 세션에 한두 줄로 알려 주면 된다(예: "10장 서재 아직 어려움, 잠김 잘 됨, 도트 머리 괜찮음").
