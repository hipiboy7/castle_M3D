## 📱 설치

1. 휴대폰 **GitHub 앱** → 아래 **Repositories** → `castle_M3D` → **Releases** → 맨 위(**Latest**) 릴리스
2. 아래 **Assets** 에서 `castle_m3d-<버전>.apk` 를 눌러 받고 → 열어서 **설치**(처음이면 '출처를 알 수 없는 앱' 허용)
3. 전에 깐 캐슬 M 3D 위에 그대로 덮어 설치된다(같은 서명 키)

## ⏱ 1분 플레이 경로

시작 → 결투 → '기술'로 **각법** 한 번 → 백도찬 첫 엇박(슬로모션 · 엇박 계열 습득) → 2차 → 결과

## ✅ 이번에 볼 것 (S1 공통 받기)

- [ ] 앱이 켜지고 결투가 시작된다
- [ ] 기술 이름: '각법' · '리천식 삼연타', 습득 뒤 '엇엇박 찌르기' · '엇박 찌르기' · '반대발 엇박 찌르기' — 왼쪽 위 글자가 잘리지 않는지
- [ ] 기술 게이지가 전보다 빨리 찬다(2배) — 기술을 너무 자주 쓰게 되는지 손맛 의견
- [ ] 접은 화면(커버) · 펼친 화면에서 화면 표시 · 터치 버튼 자리, 게임 중에 접고 펼 때 꺼지지 않는지
- [ ] 습득 순간 '엇박 기절 50%' 와 '엇박을 보았다' 글자가 겹치는 게 거슬리는지

결과는 Claude 세션에 한두 줄로 알려 주면 된다(예: "1 OK, 2 잘림, 3 너무 빠름 …").
