## 📱 설치

1. 휴대폰 **GitHub 앱** → 아래 **Repositories** → `castle_M3D` → **Releases** → 맨 위(**Latest**) 릴리스
2. 아래 **Assets** 에서 `castle_m3d-<버전>.apk` 를 눌러 받고 → 열어서 **설치**(처음이면 '출처를 알 수 없는 앱' 허용)
3. 전에 깐 캐슬 M 3D 위에 그대로 덮어 설치된다(같은 서명 키)

## ⏱ 1분 플레이 경로 (S5 묶음 4 — 2장 하성 본사)

처음 화면 **2장** 카드 → 공사장 밤(김신 맨손 대 이슬 한 합) → 하성 로비(**서진태**를 조작 · 이슬 · 청년회가 아군) —
싸우다가 **메뉴**로 '위층 복도'(남궁혁 따돌리기) · '부진폐차장 · 밤'(신태진)으로 바로 가 본다.

## ✅ 이번에 볼 것 (v0.6.0-rc.2 — 2장 하성 본사 · 전 인물 외형 다시)

- [ ] **6장 멈춤 다시 보기**(rc.1 에서 싸움 중 메뉴 → 6장으로 가면 화면이 굳음): 아무 장에서 싸우다 **메뉴 → 6장 → 스테이지** — 이번엔 굳지 않는지. 굳으면 "어느 장에서 갔는지 · 오른쪽 위 FPS 숫자"를 알려 준다. 처음 화면 6장 카드로도 한 번
- [ ] **캐릭터 크기**: 메인 인물(김신 · 서진태 · 보스)이 무리(조직원 · 경호원)보다 조금 크고, 전보다는 작은지 · **머리가 전보다 작은지**(그림 A · B · 인형 모두 — rc.2 에서 도트도 새 크기)
- [ ] **외형(원작 대조로 52명 다시)**: 처음 화면 '그림' 버튼으로 A · B 를 바꿔 가며 — 인물이 원작과 닮았는지 · 여성 인물 · 수염 색 · 이상하게 깨진 모델이 없는지
- [ ] 처음 화면 카드에 **2장**이 열려 있고, 1장을 깨면 이어하기가 2장
- [ ] 방마다 조작 인물이 바뀌는지: 공사장 · 대표실 앞 · 대표실 · 위층 · 폐차장 = 김신, 로비 · 중앙계단 = **서진태**(칼) — 교대 버튼은 안 보인다
- [ ] 김신: 공사장은 **맨손**, 하성 본사부터 **역수 단검**(베기)
- [ ] **서진태 조작** 손맛: 베기 → 되베기 → 회전 베기 · 낮은 대시 · 막기(쳐내기 없음) — 사람이 하기에 괜찮은지
- [ ] **황보민철**(중앙계단): 단검 둘 · 얼굴 스치는 맞받기, 2차 '미끼'(다친 다리로 무너지는 척) — 서진태로 깰 만한지
- [ ] **오지인**(대표실 앞): 경호팀과 싸우다 체력이 줄면 칼을 내려놓고 **비켜서는지**(원작대로)
- [ ] **남궁혁**(위층 복도 — 따돌리기): 아래 알림 줄에 남은 초 · 40초 버티거나 **오른쪽 끝 문**에 닿으면 넘는다 · 너클 카운터가 무서운지 · 쓰러지지 않는다
- [ ] **신태진**(폐차장 밤 — 2장 끝 보스): 쌍칼 · 2차(두 번째 칼) — 1장 윤덕수보다 조금 센 정도인지
- [ ] 인물 구별(그림 A): 신태진 · 남궁혁 · 황보민철 · 이슬 · 오지인 · 김재훈 · 강창석 · 하성 조직원 · 경호팀 · 청년회
- [ ] 무대: 하성 로비 · 중앙계단 · 대표실 앞 복도 · 대표실(깨진 창) · 위층 복도(출구) — 어디인지 알아볼 만한지 · FPS
- [ ] 대사 · 방 이름 · 남은 초 글이 화면에 잘리지 않는지(접은 화면 · 펼친 화면)
