## 📱 설치

1. 휴대폰 **GitHub 앱** → 아래 **Repositories** → `castle_M3D` → **Releases** → 맨 위(**Latest**) 릴리스
2. 아래 **Assets** 에서 `castle_m3d-<버전>.apk` 를 눌러 받고 → 열어서 **설치**(처음이면 '출처를 알 수 없는 앱' 허용)
3. 전에 깐 캐슬 M 3D 위에 그대로 덮어 설치된다(같은 서명 키)

## ⏱ 1분 플레이 경로 (v0.7.0-rc.10 — 공격 동작 다양화 · 등급 능력)

처음 화면 → 장 카드 → 싸움 중 **메뉴**로 스테이지를 골라 바로 본다. 추천: 3장 청주 교도소 샤워장(구일화 교대) · 4장 회암시 당구장(똘배 큐) · 11장 28층(김신 대 경호대 — 회피).

## ✅ 이번에 볼 것 (v0.7.0-rc.10)

- [ ] **공격 동작이 사람마다 다른지**: 기본 연타 · 대시 공격이 인물마다 다르다(예: 한태철 골프채 휘두르기 → 되휘두르기 → 풀스윙, 쿄지 프라이팬, 메드베디 징 장갑, 똘배 큐 찌르기). 이름 있는 적 40명도 원형 동작 대신 저마다의 동작
- [ ] **동작이 크게 보이는지**: 공격 자세가 5단계(움츠림 → 젖힘 → 치기 → 지나침 → 돌아옴)로 늘고 몸 기울기 · 발 디딤이 커졌다. 메치기의 크게 젖히는 자세가 어색하지 않은지
- [ ] **적 · 아군이 기술을 더 자주 쓰는지**(이름이 머리 위에 뜬다)
- [ ] **등급 능력**(외성 하위 = 기준): 윗급일수록 동작이 빠르고(재앙 1.3배) · 체력이 많고(재앙 1.5배) · 세다(재앙 1.4배). 한참 아랫급의 공격은 저절로 비켜 피하고(머리 위 '회피' — 많아야 45%) 맞아도 덜 들어간다(바닥 50%). 재앙(리천 이긴 김신)은 외성 미만의 공격을 거의 다 피한다
- [ ] **부동심**(크리티컬 — 피해 2배, 머리 위 '부동심'): 윗급일수록 잦고 재앙 김신 · 아킬라가 가장 잦다
- [ ] **10장 산 기슭 아킬라 대 구스타프**: 구스타프 피가 반이 되면 뒤에 뜨거운 피 셋 → 총격전(아킬라 기본 공격이 리볼버 속사)
- [ ] **아랫급이 윗급을 이기는 방**(6장 앞 선창 피우진 대 남궁혁 · 10장 도서관 서진태 대 유우성 · 12장 신겐 1 · 2차전): 너무 어렵거나 쉽지 않은지
- [ ] **3장 샤워장 구일화**: 이슬 · 구일화를 바꿔 가며 조작(교대 버튼)

결과는 Claude 세션에 한두 줄로 알려 주면 된다(예: "9장 클럽 연출 좋음, 12장 개전 느림, 11장 주차장 너무 어려움").
