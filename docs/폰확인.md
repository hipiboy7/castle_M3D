## 📱 설치

1. 휴대폰 **GitHub 앱** → 아래 **Repositories** → `castle_M3D` → **Releases** → 맨 위(**Latest**) 릴리스
2. 아래 **Assets** 에서 `castle_m3d-v0.7.0-rc.21.apk` 를 눌러 받고 → 열어서 **설치**(처음이면 '출처를 알 수 없는 앱' 허용)
3. 전에 깐 캐슬 M 3D 위에 그대로 덮어 설치된다(같은 서명 키 · 세이브 유지)
