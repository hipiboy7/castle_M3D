## 📱 설치

1. 휴대폰 **GitHub 앱** → 아래 **Repositories** → `castle_M3D` → **Releases** → 맨 위(**Latest**) 릴리스
2. 아래 **Assets** 에서 `castle_m3d-<버전>.apk` 를 눌러 받고 → 열어서 **설치**(처음이면 '출처를 알 수 없는 앱' 허용)
3. 전에 깐 캐슬 M 3D 위에 그대로 덮어 설치된다(같은 서명 키)

## ⏱ 1분 플레이 경로 (v0.7.0-rc.2 — 3 ~ 13장 첫 판)

처음 화면 장 카드가 **세 줄**(프롤로그 ~ 13장 · 6장은 '앞'(배 위)과 결투 둘)이 됐다 → **3장** 카드 → 감방(이슬) 한 판 → 메뉴(싸움 중 왼쪽 위) → 스테이지에서 다른 방 · 다른 장으로 건너뛰며 본다.
마지막은 **13장** → 붉은 하늘 공터 '주먹 승부'(김신 맨손 대 피우진).

## ✅ 이번에 볼 것 (v0.7.0-rc.2)

### 3 ~ 13장 — 장마다 한 판씩(새로)
- [ ] **3장** 청주 감방(이슬 대 구일화) · 클럽 발레리노(피우진 대 바실리) · 오락실(서진태 대 표영) · 밤 시장 골목(김신 · 서진태 교대 — 남일호 물러남) · ROLLING BALL(김신 대 불곰) · 모승규 사무실(**표영 조작** — 카람빗) · 부산 거리(**12초 안에 오른쪽 끝** — 오도화 따돌리기)
- [ ] **4장** 당구장(이슬 대 똘배) · 불법 무투장 케이지(김신 맨손) · 클럽 칼잡이(피우진) · 시베리아 작업장(피우진 대 드미트리) · 저수지 물가 집(김신 대 구스타프) · 공단 폐공장(**김대건 조작** 대 바리스타) → 끝(백도찬 · 김대건의 죽음은 대사)
- [ ] **5장 · 7장**: 싸움 없는 장 — 대사가 3.4초마다 흘러가고 저절로 넘어가는지(너무 빠른지 · 느린지)
- [ ] **6장 앞**(배 위): 김신 · 피우진 · 서진태 **셋 교대**(갑판) · 서진태 대 코모도(선교) · 피우진 대 남궁혁(선창 — 너클 카운터) → 6장 결투(김신 대 백도찬)로 이어지는지
- [ ] **8장** 동남아 항구(피우진) · 웨스턴 펍(스케일단장) · 물류창고(마크) · 교류회장(김신 대 류지학 — 물러남)
- [ ] **9장** 백의 사무실(김신 + 똘배 아군) · 클럽 부다페스트 · 선박 카지노(사천왕) · 붉은 기둥 회랑(**리천에게서 12초 퇴각**)
- [ ] **10장** 철공소 아케이드(김신 대 리천 — 톱끼리) · 아파트 단지(피우진 대 도우첸) · 화진 호텔 홀(김신 · 서진태 교대) · 서재(서진태 대 유우성)
- [ ] **12장** 빗속 교회 마당(마준영) · 녹색 사무실층(구스타프) · 교회 복도(피우진 → 김신 교대 대 신겐) · 공사장(그롤라) · 지하 복도(엄지 · 검지) · 지하 주차장(**마학영 — 최종 보스, 떨어지면 권총**)
- [ ] **13장** 미술관 앞(도학수 · 어광득) · 사인진 · **주먹 승부**(김신 맨손 대 피우진) → 맺음 대사 → 끝
- [ ] **난이도**: 장마다 '너무 쉬움 · 알맞음 · 너무 어려움' — 특히 아랫급이 조작하는 방(이슬 · 피우진 · 표영 · 김대건)과 12장 보스들
- [ ] **무대**: 장소가 그 장면처럼 보이는지(감방 창살 · 케이지 철망 · 슬롯머신 · 빗속 골목 · 배 갑판 · 선박 카지노 붉은 기둥 · 교회 · 미술관) — 가장 아쉬운 무대 두셋
- [ ] **인물 외형**: 새 이름 있는 인물 44명은 명부 그림(그림 A) — 누가 원작과 너무 다른지. 그림 B(도트)는 굳힌 명부 시트(예전 얼굴)
- [ ] 이름 없는 무리(재소자 · 가면 · 선원 · 화진 습격조 · 교회 경호대)는 옷만 바뀐 같은 무리 — 거슬리는지
