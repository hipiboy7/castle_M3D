## 📱 설치

1. 휴대폰 **GitHub 앱** → 아래 **Repositories** → `castle_M3D` → **Releases** → 맨 위(**Latest**) 릴리스
2. 아래 **Assets** 에서 `castle_m3d-<버전>.apk` 를 눌러 받고 → 열어서 **설치**(처음이면 '출처를 알 수 없는 앱' 허용)
3. 전에 깐 캐슬 M 3D 위에 그대로 덮어 설치된다(같은 서명 키)

## ⏱ 1분 플레이 경로 (v0.7.0-rc.3 — 난이도 · 김대건 머리)

처음 화면 왼쪽 **난이도** 버튼(그림 · 성능 아래)을 눌러 쉬움 → 보통 → 어려움 → 헬 중 고른다(고른 값은 다음 실행에도 남는다) → **4장** 카드 → 맨 끝 공단 폐공장(김대건 조작)으로 건너뛰어 김대건 머리를 본다.

## ✅ 이번에 볼 것 (v0.7.0-rc.3)

- [ ] **난이도 버튼**: 누를 때마다 글이 쉬움 · 보통 · 어려움 · 헬로 바뀌는지, 앱을 껐다 켜도 고른 값이 남는지(접은 · 펼친 화면 둘 다 버튼이 보이는지)
- [ ] **난이도 차이**: 같은 방을 쉬움과 헬로 한 판씩 — 적 체력 · 맞는 아픔 · 몰아치는 빠르기가 확실히 다른지. 보통은 rc.2 와 같다
  - 쉬움: 적 체력 70% · 피해 60% · 공격 사이 길게 / 어려움: 130% · 140% · 짧게 / 헬: 170% · 200% · 더 짧게 (조작 인물 · 아군은 그대로)
- [ ] **김대건 머리**: 1장 폐차장 · 4장 폐공장 — 정수리 · 뒤통수가 맨살로 뚫려 보이지 않는지. 같은 짧은 머리 인물(강만재 · 이슬 · 남일호 · 구스타프 · 코모도 · 장호 · 판테라 · 경호대 4인 등)도 뒤통수가 덮였다

결과는 Claude 세션에 한두 줄로 알려 주면 된다(예: "3장 감방 너무 어려움, 5장 대사 빠름, 12장 마학영 너무 쉬움, 교회 무대 별로").
