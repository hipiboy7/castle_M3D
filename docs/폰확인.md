## 📱 설치

1. 휴대폰 **GitHub 앱** → 아래 **Repositories** → `castle_M3D` → **Releases** → 맨 위(**Latest**) 릴리스
2. 아래 **Assets** 에서 `castle_m3d-<버전>.apk` 를 눌러 받고 → 열어서 **설치**(처음이면 '출처를 알 수 없는 앱' 허용)
3. 전에 깐 캐슬 M 3D 위에 그대로 덮어 설치된다(같은 서명 키)

## ⏱ 1분 플레이 경로 (v0.7.0-rc.12 — 화풍 바꿈 1단계)

처음 화면(뒤에 도는 데모) → 1장 · 2장 · 6장 · 9장 카드를 차례로 30초씩. 처음 화면 **'그림'** 버튼은 이제 **A(붓칠 먹선) ↔ 관절 인형** 둘만 바뀐다.

## ✅ 이번에 볼 것 (v0.7.0-rc.12 — Hades 화풍 1단계: 그리는 방식)

- [ ] **먹선**: 인물 · 소품 · 벽 바깥에 굵은 검은 윤곽(화면 크기에 맞춰 굵기가 같다 — 접어도 · 펴도)
- [ ] **명암**: 그러데이션 대신 그림자 · 중간 · 밝은 면 세 단으로 딱 끊긴다 · 그림자는 차갑고 보랏빛 · 빛을 받는 쪽 가장자리에 그 빛 색 테두리
- [ ] **바닥**: 붓 결 · 얼룩 · 회색 땅(아스팔트 · 콘크리트)엔 군데군데 금 · 바닥이 인물보다 한 단 어두워 인물이 떠 보인다(2장 흰 대리석 로비도)
- [ ] **화면 마무리**: 채도 · 대비 올림 · 가장자리 짙은 비네트 · 종이 결
- [ ] **카메라**: 화각을 좁히고(38 → 30도) 멀리서 · 내려다보는 각 약 55도 — 원근이 납작해져 그린 그림처럼. 인물 크기는 그대로
- [ ] 폰에서 **끊김(프레임)** 이 생겼는지 — 먹선 · 붓 결 셰이더가 더해졌다(11장 주차장 · 2장 로비처럼 사람이 많은 방)
- [ ] 너무 어둡거나 · 밝거나 · 먹선이 굵거나 가는 장이 있으면 장 이름으로
- 다음(2단계): 인물 모델 다시 깎기(공 · 캡슐 조각 → 이어진 몸 · 손가락 · 옷 주름) — 이번엔 그리는 방식만 바뀌었다
