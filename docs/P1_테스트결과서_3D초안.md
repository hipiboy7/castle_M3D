## 2. 자체 점검에서 찾아 고친 것

| 찾은 것 | 조치 |
|---|---|
| 빈틈인 상대를 연타 중에 치면 제압이 아니라 다음 연타가 나갔다(테스트가 잡음) | 연타 이음보다 반격 · 제압을 먼저 고른다(`fighter.gd` `_special_attack`) |

자체 점검(스크린샷에서 찾은 것 — 다음 묶음에서 고친다):
1. 카메라가 멀다 — 인물이 화면 높이의 약 1/5. 팔다리 입체감을 판단하기 어렵다 → 더 가깝게(인물 1/3 정도)
2. 바닥 무늬(젖은 아스팔트 잡음)가 너무 크고 대비가 세서 구름 · 대리석처럼 보인다 → 잘게 · 어둡게 · 대비 낮춤
3. 맞음 번쩍임이 몸 전체를 흰색으로 만든다 → 짧고 약하게(색을 섞는 정도)
4. 칼 궤적(특히 세 바퀴 돌기)이 불투명한 흰 판 → 얇게 · 반투명 · 끝으로 갈수록 사라지게
5. 머리카락이 헬멧처럼 보인다 → 머리 모양(김신 짧은 머리 · 백도찬 가르마). GLB 단계에서 바뀔 부분이라 작게
