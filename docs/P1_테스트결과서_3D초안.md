## 2. 자체 점검에서 찾아 고친 것

| 찾은 것 | 조치 |
|---|---|
| 빈틈인 상대를 연타 중에 치면 제압이 아니라 다음 연타가 나갔다(테스트가 잡음) | 연타 이음보다 반격 · 제압을 먼저 고른다(`fighter.gd` `_special_attack`) |
| 서로를 붙잡은 참조(상대 · AI)로 종료 때 객체 누수 경고 | 상대는 약한 참조(`set_target` · `target()`) |
| 창 없는 실행에서 소리를 내면 종료 때 재생 객체가 남는다(가짜 오디오) | 창 없는 실행에서는 소리를 내지 않는다(`main.gd` `_play` · `_music`) |
| 김신 체력이 castle_M 값(120)이면 봇이 6판 중 4판 진다 | 초안은 200(잠정, `duel.gd` 머리 주석). 체간 60 · 백도찬 400 · 220 은 castle_M 그대로 |
